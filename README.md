# ReplyFlow AI

An AI-powered customer conversation management platform that helps businesses manage customer interactions, generate AI-assisted replies, and identify potential leads.

## ✨ Features

- 🤖 **AI Reply Generation** — Generate customer replies using Google Gemini with customizable tone and length.
- 💬 **Conversation Management** — Create and manage customer conversations with persistent follow-up messages.
- 🔥 **Lead Management** — Convert potential customers into leads.
- 📊 **Analytics** — View conversation and lead activity.
- 🔐 **Authentication & Security** — Supabase authentication with Row Level Security (RLS).
- 🌓 **Responsive UI** — Modern responsive interface with dark/light mode.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Google Gemini API
- Vercel

## 🚀 Getting Started

### 1. Clone the repository
git clone https://github.com/Navindi-Thisara/replyflow-ai.git
cd replyflow-ai

### 2. Install dependencies
npm install

### 3. Configure environment variables
Create .env.local:

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

GEMINI_API_KEY=your_gemini_api_key

### 4. Run the application
npm run dev

Open http://localhost:3000.
